# 冷库需量账单峰值核账（同期换表接续）

Flask + SQLite 的核账页：上传整分钟累计用电 CSV（整数 Wh，电表不回卷），
支持**同一账期内多次换表**并把多块电表的读数折算成一条连续累计序列；
核对账单所报 15 分钟峰值时段是否存在一种整数分钟用电分配，使该时段**恰好**
达到账单峰值、其余不重叠的 15 分钟时段均**不超过**该值。

## 换表接续规则

- 网页可在**现用表末次实读的分钟**登记新表编号与起始读数；交接分钟必须
  **晚于现用表首读**，同一期可多次换表（最多 31 次）。
- 旧库读数全部归首表（`M1`，seq=0）；每次换表生成一条换表记录。
- 补传时先选择**电表的使用时段**：时段以交接分钟为界，**两侧均含该分钟**。
  其他使用时段只可读对应的交接读数，越界写入整批拒绝。
- 同一 (分钟, 电表) **同刻覆盖**：可分别更正旧表末读数和新表起始读数；
  更正后按交接顺序重算全部偏移与统一接续值。
- 读数越界（负数）、单表回卷、合并后接续序列回卷，或超过原每分钟用电
  上限，**整批拒绝，接续值照旧**。
- **累计值从首表原示数起算**：首表偏移为 0；每次交接把旧表末读折算成
  统一接续值 `U`，新表偏移 = `U − 新表起始读数`，交接分钟两侧折算成
  同一个值（序列中该分钟只保留一个点）。
- 换表或交接读数更正成功后，旧的**当前结论和对应 CSV 暂停提供**
  （`audits.suspended=1`，初核结论始终保留）；用接续值重新核对成功后
  恢复供数。
- 清空账期会一并清空换表记录、电表登记与接续汇总。

### 行数预算

- `meter_changes` 最多 31 条，`continuation_summary` 固定 1 条，
  **换表记录 + 接续汇总合计最多 32 条**。
- 按分钟查询只做该分钟的索引点查（交接分钟至多返回两块表各 1 行实读），
  不做全表扫描；接续偏移由截至该分钟的换表记录（≤31 条）链式推出。

## 模型与算法（不逐分钟铺开缺读段，也不逐 Wh 分配）

- 求解器输入为折算后的**接续序列**，与单表路径完全一致。
- 时间轴只按「相邻实读之间的段」×「15 分钟窗」的**交集切块**，块数
  O(读数数 + 窗数)，与缺读段内分钟数、Wh 数无关。31 天仅首尾两读数时
  块数 = 2976（窗数），而不是 44640 分钟。
- 每块是整数变量 x∈[L,H]：`L=max(0, d-(n-k)U)`、`H=min(kU, d)`，
  其中 n 为段内分钟数、k 为块内分钟数、d 为段固定电量、U 为每分钟上限。
- 段→窗构成二部流：S→段固定为段电量 d，块边带 [L,H] 下界，窗→T 带界。
  区间矩阵全幺模，整数解与 LP 解等价。
- **可行判定**：带下界可行流（Dinic + 超源/超汇）。
- **所报窗可达区间**：对目标值二分，分别求最小/最大可达电量。
- **最小越限方案**：最小费用流（势 + Dijkstra），其它窗的守限部分费用 0、
  越限部分费用 1/Wh，得到最小越限总量与被迫越限的窗。

## 三种结论

| status | 含义 |
| --- | --- |
| `feasible` | 存在分配：所报窗恰为峰值，其余窗均不超过；列出全期各窗电量 |
| `target_unreachable` | 所报时段本身达不到该值，附其可达区间 [min, max] |
| `others_breach` | 所报窗可达，但其余时段无法同时守住上限，附最小越限量与越限窗 |

## 数据规则

- 账期取接续序列首末读数，两端必须对齐 15 分钟边界，最长 31 天。
- 账期内可补传，**同刻覆盖**；合并后若回卷或超过每分钟上限导致实读无解，
  **整批拒绝**并指出冲突的相邻读数，库内数据、换表记录与结论不变。
- `initial` 结论只写一次并保留；`current` 随读数/参数每次更新；
  核对失败（参数非法或实读无解）不覆盖当前结论。
- 旧版数据库（`readings` 无 `meter_seq`、`audits` 无 `suspended`）
  首次打开时自动迁移，老读数归入首表。

## CSV 格式

```
timestamp,reading
2026-11-01 00:00,0
2026-11-01 00:15,30
```

## 网页操作

1. 补传读数：选择电表使用时段后上传 CSV（首表为 `M1`）。
2. 登记换表：填交接分钟（现用表末次实读分钟）、新表编号、新表起始读数。
3. 按分钟查询：`GET /minute?minute=2026-11-05 09:30`（加 `&format=json`
   返回 JSON），只返回该分钟实读、换表记录与接续值。
4. 暂停期间页面给出黄色提示，`windows.csv` 返回 302 引导重新核对。

## 启动

### Docker Compose（推荐）

```bash
docker compose up -d --build
# 打开 http://localhost:8000
```

SQLite 数据持久化在命名卷 `meter-data`（容器内 `/data/meter.db`）。

### 本地直接运行

```bash
pip install -r requirements.txt
python wsgi.py            # 开发服务器，:8000
# 或
gunicorn --bind 0.0.0.0:8000 wsgi:app
```
